# 블록 딜레마 (Block Dilemma)

> 예전 이름: 둘 중 하나 / Either Or. 저장소 이름·웹 주소·패키지 ID 는 기록 보존을 위해 예전 그대로다.

블록 두 개 중 하나를 골라 8×8 보드에 놓고, 가로 줄을 채워 지우는 퍼즐 게임.
인터넷 없이도 돌아가는 웹 게임(PWA)이라 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 어떻게 하는 게임인가

1. **크기 고르기** — 블록 크기 두 개 중 하나를 고릅니다. 큰 블록일수록 점수가 높습니다.
2. **모양 고르기** — 그 크기의 블록이 두 개 나옵니다.
3. **놓기** — 두 가지 방법이 있습니다.
   - ✏️ **그리기**: 보드 빈칸을 손가락으로 칠하면 모양이 맞을 때 놓입니다. 돌리는 건 되고, 뒤집는 건 안 됩니다.
   - ✋ **끌어놓기**: 탭해서 돌리고 보드로 끌어다 놓습니다. PC에서는 끄는 중에 R키로도 돌아갑니다.
4. **📦 보관** — 지금 안 쓸 블록을 넣어뒀다 나중에 꺼내 쓸 수 있습니다. 대신 그 턴은 넘어갑니다.
5. 가로 한 줄이 꽉 차면 사라지고 위 블록들이 내려옵니다. 놓을 곳이 없으면 게임 끝.

난이도를 올리면 회색 방해 블록이 주기적으로 떨어지는 대신 점수 배율이 최대 3배가 됩니다.

## 실행

그냥 `index.html`을 열어도 게임은 돌아가지만, `file://`로 열면 **기록 저장이 안 됩니다**
(브라우저가 로컬 파일에서는 저장소를 막습니다). 로컬 서버로 띄우세요:

```bash
python -m http.server 8123
```

그리고 http://localhost:8123 을 엽니다.

## 파일

| 파일 | 뭔지 |
|---|---|
| `index.html` | 게임 전부 (CSS·JS 한 파일, 외부 라이브러리 없음) |
| `manifest.json` | 앱 이름·아이콘·세로 고정 |
| `sw.js` | 서비스 워커 — 오프라인 실행용 캐시 |
| `icons/` | 앱 아이콘 |
| `fonts/` | 내장 폰트 (실제 쓰는 글자만 담아서 62KB) |
| `tools/make-icons.py` | 아이콘 생성기 |
| `tools/build-fonts.py` | 폰트 다운로더 |

## 고칠 때 주의할 것

- **한글 문구를 새로 추가했으면** `python tools/build-fonts.py`를 다시 돌리세요.
  폰트에 그 글자가 없어서 시스템 기본 폰트로 나옵니다(깨지진 않습니다).
- **`sw.js`의 `ASSETS` 목록을 고쳤으면** 같은 파일의 `VERSION`을 올리세요.
  안 올리면 예전에 저장된 파일이 계속 쓰입니다.
- 아이콘 색이나 모양은 `tools/make-icons.py` 위쪽 상수만 고치고 다시 돌리면 5종이 한 번에 만들어집니다.
